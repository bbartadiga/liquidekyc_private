## Step 1: Persiapan

Pastikan kamu sudah memiliki hal-hal berikut sebelum memulai:

- Akun Admin ProTech ID Checker (diberikan oleh vendor PIC)
- JS Tag dari vendor PIC, contoh:
```html
  <script charset='utf-8' src='https://app.protechidchecker.com/apps/org4120'></script>
```
- Akses ke dashboard PIC: `https://console.protechidchecker.com/`
- Flutter project yang sudah berjalan
- Akun hosting (Firebase Hosting / Netlify / Vercel / GitHub Pages / server sendiri)

---

## Step 2: Membuat Halaman HTML Host

Buat file `index.html` dengan isi berikut:
```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Verifikasi Identitas</title>
    <style>
        body {
            margin: 0;
            padding: 0;
            font-family: sans-serif;
        }
    </style>
</head>
<body>

    <!-- PIC akan render kontennya di sini -->
    <div id="pic-container"></div>

    <!-- JS Tag dari vendor PIC -->
    <script charset='utf-8' src='https://app.protechidchecker.com/apps/org4120'></script>

</body>
</html>
```

> **Catatan:** Ganti `org4120` dengan organization ID milikmu jika berbeda.

## Step 3: Upload ke Hosting

Halaman HTML ini **harus di-hosting** agar memiliki URL `https://` yang valid. PIC memerlukan URL yang valid untuk whitelist (HTTP Referer).

### Contoh: Menggunakan Firebase Hosting

#### 3.1 Install Firebase CLI
```bash
npm install -g firebase-tools
```

#### 3.2 Login ke Firebase
```bash
firebase login
```

#### 3.3 Buat folder project
```bash
mkdir pic-ekyc-page
cd pic-ekyc-page
```

#### 3.4 Inisialisasi Firebase Hosting
```bash
firebase init hosting
```

Saat ditanya:
- **Public directory:** `public`
- **Configure as single-page app:** `No`
- **Set up automatic builds with GitHub:** `No`

#### 3.5 Pindahkan file HTML

Taruh `index.html` ke dalam folder `public/`:
```
pic-ekyc-page/
  └── public/
        └── index.html
```

#### 3.6 Deploy
```bash
firebase deploy --only hosting
```

#### 3.7 Catat URL

Setelah deploy berhasil, kamu akan mendapatkan URL seperti:
```
https://pic-ekyc-page.web.app
```

> **Simpan URL ini — akan digunakan di step selanjutnya.**

## Step 4: Konfigurasi di Dashboard PIC

Login ke `https://console.protechidchecker.com/` menggunakan akun Admin.

### 4.1 Registrasi Halaman

1. Masuk ke menu **ページ登録** (Page Registration)
2. Klik **ページを登録する** (Daftar Halaman Baru)
3. Isi form:
   - **ページのURL (Page URL):** `https://pic-ekyc-page.web.app`
   - **ページ名 (Page Name):** `Flutter eKYC Page` (atau nama lain sesuai keinginan)
4. Klik **新規ページを登録する** (Daftar)

### 4.2 Aktifkan Aplikasi

1. Masuk ke **ページ編集** (Page Edit)
2. Set **アプリの起動** (App Launch) ke **起動** (Aktif)

### 4.3 Pengaturan Bahasa

- Pilih **日本語** (Jepang) atau **英語** (Inggris) sesuai kebutuhan

### 4.4 Pengaturan Autentikasi

1. Masuk ke bagian **認証の設定** (Authentication Settings)
2. Tambahkan **本人確認操作** (Identity Verification Operation):
   - Isi nama verifikasi
   - Pilih step yang dibutuhkan:
     - **身分証明書の書類撮影** — foto dokumen identitas (kamera belakang)
     - **顔静止画像撮影** — foto selfie (kamera depan)
     - **顔動画撮影** — video gerakan wajah kiri/kanan (kamera depan)
   - Konfigurasi fitur tambahan sesuai kebutuhan:
     - AI cek ketajaman & kelengkapan foto
     - OCR (baca data dari dokumen)
     - Pencocokan wajah otomatis
     - Cek topi / masker

### 4.5 Pengaturan Redirect

1. Scroll ke bagian **リダイレクト設定** (Redirect Settings)
2. ON-kan **本人確認完了後のリダイレクト** (Redirect setelah verifikasi selesai)
3. Isi **リダイレクトURL** dengan URL sinyal:
```
   https://myapp.com/ekyc-done
```
   > URL ini tidak perlu benar-benar ada. Hanya digunakan sebagai sinyal yang akan di-intercept oleh Flutter.
4. Set delay redirect: **1 detik** (atau sesuai kebutuhan, range 1-9 detik)

### 4.6 Whitelist (API Settings)

1. Masuk ke menu **設定** (Settings) → **API設定** (API Settings)
2. Daftarkan:
   - **HTTP Referer:** `https://pic-ekyc-page.web.app`
   - **IP Address:** IP server (opsional, harus IP Jepang)
3. Ambil **Access Token** dan **Decryption Key** jika diperlukan untuk integrasi backend

## Step 5: Setup Permission Native (Android & iOS)

### 5.1 Android

Edit file `android/app/src/main/AndroidManifest.xml`, tambahkan permission berikut di dalam tag `<manifest>`:
```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.CAMERA" />
```

### 5.2 iOS

Edit file `ios/Runner/Info.plist`, tambahkan:
```xml
<key>NSCameraUsageDescription</key>
<string>Kami membutuhkan akses kamera untuk proses verifikasi identitas.</string>
```

## Step 6: Setup WebView di Flutter

### 6.1 Install Package

Tambahkan dependency di `pubspec.yaml`:
```yaml
dependencies:
  flutter_inappwebview: ^6.0.0
```

Jalankan:
```bash
flutter pub get
```

### 6.2 Buat Halaman WebView

Buat file `lib/ekyc_webview_page.dart`:
```dart
import 'package:flutter/material.dart';
import 'package:flutter_inappwebview/flutter_inappwebview.dart';

class EkycWebViewPage extends StatelessWidget {
  const EkycWebViewPage({super.key});

  // URL sinyal redirect — harus sama dengan yang diset di dashboard PIC
  static const String _redirectSignalUrl = "https://myapp.com/ekyc-done";

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Verifikasi Identitas'),
        leading: IconButton(
          icon: const Icon(Icons.close),
          onPressed: () => Navigator.pop(context, "cancelled"),
        ),
      ),
      body: InAppWebView(
        // Load halaman HTML yang sudah di-hosting
        initialUrlRequest: URLRequest(
          url: WebUri("https://pic-ekyc-page.web.app"),
        ),

        // Pengaturan WebView
        initialSettings: InAppWebViewSettings(
          javaScriptEnabled: true,
          mediaPlaybackRequiresUserGesture: false,
          allowsInlineMediaPlayback: true,
        ),

        // Auto-grant permission kamera
        onPermissionRequest: (controller, request) async {
          return PermissionResponse(
            resources: request.resources,
            action: PermissionResponseAction.GRANT,
          );
        },

        // Intercept URL redirect dari PIC
        shouldOverrideUrlLoading: (controller, navigationAction) async {
          final url = navigationAction.request.url.toString();

          // Cek apakah URL yang di-load adalah URL sinyal redirect
          if (url.startsWith(_redirectSignalUrl)) {
            // Ambil parameter tambahan jika ada (opsional)
            final uri = Uri.parse(url);
            final identity = uri.queryParameters['Identity'];

            // Verifikasi selesai — tutup WebView dan kirim result ke Flutter
            Navigator.pop(context, {
              "status": "success",
              "identity": identity,
            });

            // Cancel loading URL sinyal (tidak perlu benar-benar dibuka)
            return NavigationActionPolicy.CANCEL;
          }

          // URL lain tetap di-load seperti biasa
          return NavigationActionPolicy.ALLOW;
        },
      ),
    );
  }
}
```

## Step 7: Memanggil WebView dari Halaman Flutter

Contoh cara memanggil halaman WebView dan menangani hasilnya:
```dart
import 'package:flutter/material.dart';
import 'ekyc_webview_page.dart';

class HomePage extends StatelessWidget {
  const HomePage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Home')),
      body: Center(
        child: ElevatedButton(
          onPressed: () => _startEkyc(context),
          child: const Text("Mulai Verifikasi Identitas"),
        ),
      ),
    );
  }

  void _startEkyc(BuildContext context) async {
    // Buka halaman WebView dan tunggu hasilnya
    final result = await Navigator.push(
      context,
      MaterialPageRoute(
        builder: (context) => const EkycWebViewPage(),
      ),
    );

    // Tangani result
    if (result is Map && result["status"] == "success") {
      // Verifikasi berhasil
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(
          content: Text("Verifikasi identitas berhasil!"),
          backgroundColor: Colors.green,
        ),
      );

      // Lanjutkan proses berikutnya di app...
      // Misalnya: navigasi ke halaman sukses, aktifkan fitur, dll.

    } else {
      // User membatalkan atau verifikasi gagal
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(
          content: Text("Verifikasi dibatalkan."),
          backgroundColor: Colors.orange,
        ),
      );
    }
  }
}
```

## Step 8: Testing

### 8.1 Checklist Sebelum Test

- [ ] File HTML sudah di-hosting dan bisa diakses via browser
- [ ] JS Tag PIC sudah tertempel di file HTML
- [ ] URL halaman sudah didaftarkan di dashboard PIC (Page Registration)
- [ ] App Launch sudah di-set ke "Aktif" di dashboard PIC
- [ ] Metode autentikasi sudah dikonfigurasi di dashboard PIC
- [ ] Redirect URL sudah diset di dashboard PIC
- [ ] HTTP Referer sudah di-whitelist di API Settings
- [ ] Permission kamera sudah ditambahkan di Android & iOS
- [ ] Package `flutter_inappwebview` sudah terinstall

### 8.2 Cara Test

1. **Gunakan perangkat fisik** — kamera tidak tersedia di emulator
2. Jalankan app Flutter di perangkat fisik:
```bash
   flutter run
```
3. Klik tombol "Mulai Verifikasi Identitas"
4. WebView akan terbuka dan PIC akan muncul
5. Ikuti instruksi: foto dokumen → foto selfie → selesai
6. Setelah selesai, PIC akan redirect → Flutter menangkap sinyal → WebView tertutup
7. Cek apakah result "success" diterima di halaman Flutter

### 8.3 Troubleshooting

| Masalah | Penyebab | Solusi |
|---------|----------|--------|
| PIC tidak muncul di WebView | URL belum didaftarkan di dashboard PIC | Daftarkan URL di Page Registration |
| PIC tidak muncul di WebView | App Launch belum diaktifkan | Set ke "起動" (Aktif) di Page Edit |
| PIC tidak muncul di WebView | HTTP Referer belum di-whitelist | Tambahkan URL di API Settings |
| Kamera tidak bisa diakses | Permission belum ditambahkan | Tambahkan permission di AndroidManifest / Info.plist |
| Kamera tidak bisa diakses | onPermissionRequest belum di-handle | Pastikan auto-grant di WebView |
| Redirect tidak terdeteksi | URL sinyal tidak cocok | Pastikan URL di dashboard PIC sama dengan yang di-intercept di Flutter |
| Halaman blank / error | JS tidak enabled di WebView | Pastikan `javaScriptEnabled: true` |
| Freeze saat minta permission kamera (Android) | Limitasi perangkat tertentu | Coba di perangkat Android lain |

## Catatan Penting

1. **Konfirmasi ke Tim Showcase/PIC** bahwa in-app WebView Flutter didukung. PIC mendukung in-app WebView dengan syarat tertentu yang perlu dikonfirmasi.

2. **Minta dokumen "PIC JS Reference"** ke vendor untuk fitur lanjutan seperti manual launch, callback handling, dan custom parameter passing.

3. **Perangkat yang didukung PIC:**
   - Android OS 7+ / Chrome
   - iOS 15+ / Safari & Chrome
   - iPad OS 15+ / Safari & Chrome

4. **Data verifikasi otomatis terhapus** setelah 90 hari (default). Periode ini bisa diubah melalui vendor.

5. **IP Address di whitelist harus IP Jepang.** Jika server di luar Jepang, diskusikan dengan tim Showcase.

6. **Jangan test di emulator** — gunakan perangkat fisik karena membutuhkan akses kamera.
